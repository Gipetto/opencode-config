# OpenCode setup

OpenCode configuration

## Shared skills

Put portable `SKILL.md` skills in `~/.agents/skills`. This is a cross-tool Agent Skills compatibility location: OpenCode and GitHub Copilot both discover it as a global skill directory.

It is not universal. Use tool-native locations for tool-specific skills, such as `~/.config/opencode/skills` for OpenCode and `~/.copilot/skills` for GitHub Copilot.
